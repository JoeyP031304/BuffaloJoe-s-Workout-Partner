Support & accessibility

Ironlog — a free personal fitness tracker. https://joeyp031304.github.io/BuffaloJoe-s-Workout-Partner/

Get help or report a problem

Use More → Report a problem in the app. It prepares a short report (app version, device type — no personal data) that you can post as a GitHub issue or copy and send another way. You can also go straight to https://github.com/JoeyP031304/BuffaloJoe-s-Workout-Partner/issues. A free GitHub account is needed to post there.

Delete your data

More → Your data & privacy → Delete all my data removes everything Ironlog stored on your device. We keep no copy, so that is the complete deletion. If you have any concern that we hold data about you, open an issue and we will respond.

Accessibility statement

We want Ironlog to be usable by everyone, including people who use a screen reader (VoiceOver, TalkBack), keyboard navigation, large text or reduced motion. The app uses standard HTML controls with text labels, visible focus indicators, text contrast meeting WCAG 2.1 AA (4.5:1), charts and images with text descriptions, dialogs that can be closed with Escape, and respects your system's dark mode, text size and reduced-motion settings. Pinch-to-zoom is not disabled.

Known limitations: the barcode camera scanner is visual by nature (you can type the barcode instead), and the guided-circuit timer relies on colour plus the on-screen countdown and a beep. If you hit a barrier, please report it — accessibility problems are treated as bugs.

Health sync help

iPhone: install the shortcut from More → Health, run it, then tap Paste from clipboard. Android: Samsung Health → Settings → Download personal data, then open the zip in More → Health. Full details: SHORTCUT.md.
